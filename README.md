# Star River — 唐永屹的个人作品集

基于 [Creative Portfolio](https://github.com/shinekyaw/Creative-Portfolio) 模板改造的个人作品集网站。

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion

## Getting Started

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000

## Sections

- Hero — 个人介绍 + 3D 动画
- About — 背景和经历
- Skills — 技能网格
- Projects — 项目展示
- Learning Path — 学习路线
- Contact — 联系方式 + 表单
